# Search UI

Веб-интерфейс для полнотекстового поиска и управления данными. Основан на React + Ant Design.

## Основные функции

- Поиск по агрегированным данным с серверной пагинацией и сортировкой
- Фильтрация по датасетам
- Экспорт текущей страницы результатов в PDF
- Ручное добавление записей
- Загрузка CSV/JSON файлов прямо из интерфейса

## Переменные окружения

| Переменная | Описание | Значение по умолчанию |
| ---------- | -------- | --------------------- |
| `VITE_SEARCH_API_URL` | URL сервиса поиска | `http://localhost:8081` |
| `VITE_INGESTION_API_URL` | URL сервиса загрузки данных | `http://localhost:8080` |
| `VITE_PORT` | Порт dev-сервера Vite | `5173` |

## Разработка

```bash
cd frontend/search-ui
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Скомпилированная версия появится в каталоге `dist/`.
